This is navigator to find the input file tags\hypertarget{InputFile_HowToWrite}{}\doxysection{\texorpdfstring{How to write the input file}{How to write the input file}}\label{InputFile_HowToWrite}
The input file consists of key-\/value pairs where each key represents a specific setting. Each parameter should be written in the following format\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\{}
\DoxyCodeLine{\ \ \ \ parameter\_name\_1\ :\ value\_1,}
\DoxyCodeLine{\ \ \ \ parameter\_name\_2\ :\ value\_2,}
\DoxyCodeLine{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ :\ \ \ \ \ \ \ \ \ \ \ }
\DoxyCodeLine{\ \ \ \ parameter\_name\_N\ :\ value\_N}
\DoxyCodeLine{\}}

\end{DoxyCode}


Lines beginning with {\ttfamily \# or !} are considered as comments and they would be ignored.
